# Bill of Materials

| Item | Quantity | Required | Notes |
|---|---:|---|---|
| Logitech G13 Advanced Gameboard | 1 | Yes | Original retail hardware |
| Teensy 4.1 | 1 | Yes | Main USB translation controller |
| PJRC USB host cable for Teensy 3.6/4.1 | 1 | Yes | Connects to the Teensy host pads |
| Powered USB 2.0 hub with power supply | 1 | Yes for reference setup | LogiLink four-port model used successfully |
| USB-A male to Mini-USB Type-B male cable | 1 | Yes | Hub upstream connection to PJRC host socket |
| Micro-USB male to computer-side USB cable | 1 | Yes | Teensy device/client connection; USB-C used on the reference Mac |
| Pin header and soldering materials | As required | Yes | For the Teensy host connector |
| Protective enclosure | 1 | Recommended | Prevents strain and accidental shorts |

## Primary references

- Teensy 4.1: <https://www.pjrc.com/store/teensy41.html>
- PJRC USB host cable:
  <https://www.pjrc.com/store/cable_usb_host_t36.html>

Exact retailers and prices are intentionally not pinned because availability
changes. Match connector types carefully: the hub connection is Mini-USB,
whereas the Teensy device/client connector is Micro-USB.
